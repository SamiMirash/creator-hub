Original Mobile Route

You are here when: The Japanese feature-phone application manager, title menu, and first mission room.

Preserve original data before testing the partially recovered modern route.

Use the Original Japanese Mobile Release

Setup

HintThe complete historical route depended on a carrier application.
WhereRun the original application on its supported Japanese feature-phone environment.
Full detailPreserve the installed package and downloaded data together, clone the handset storage, verify Operation and Scenario menus load, and keep an untouched baseline because the retired service cannot restore missing data.

Record the Mobile Version

Setup

HintMore than one Japanese carrier received the game.
WhereRecord whether the installation is the AU release or later i-mode edition.
Full detailAt the title screen and handset application manager, capture the carrier build, device model, application version, package size, and save-data date. Do not merge progress across builds until their unlock tables are proven identical.

Document Partial Preservation Status

Setup

HintThe accessible archival reconstruction is not the whole original release.
WhereIf using the 2025 preservation build, mark it as partial before starting.
Full detailRecord the archival launcher and package hashes, test every visible mode, and keep its progress separate from original-device completion. The preservation reporting explicitly describes a partial recovery, so absent stages or server data remain verification holds.

Verify Key Configuration

Setup

HintThe keypad bindings can be changed.
WhereTest movement, aiming, interaction, firing, status, map, and menu inputs.
Full detailIn a safe opening operation, confirm the direction pad moves; while aiming it changes elevation or target; Confirm examines or fires; the right soft key toggles aim; and the left soft key opens the menu. Test the configured dash, status, and map keys before timed runs.
