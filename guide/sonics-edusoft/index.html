Prototype Setup

You are here when: The emulator launch, firmware manager, and first visible hub before any lesson begins.

Use the unmodified European prototype and a per-game Export configuration.

Verify the European Prototype

System task

HintConfirm the preserved build before changing emulator settings.
WhereHash the extracted Master System ROM and compare it with the known prototype.
Full detailUse the 262,144-byte European prototype. Its SHA-1 must be f1357505cbcebfab52327a5fc9c3437f54d8da40 and its MD5 must be 5919b101624d4710a10825c34e753ba2; do not patch the ROM to solve a boot problem.

Supply the Export Master System BIOS

System task

HintA black screen can mean missing firmware.
WherePoint the emulator at a valid USA/Europe Master System BIOS dump.
Full detailFor SMSHawk, select the 8,192-byte Export BIOS whose SHA-1 is c315672807d8ddb8d91443729405c766dd95cae7. Keep the firmware outside the game archive and let the emulator identify it as SMS+Export.

Use an Export Region Override

System task

HintThe prototype's automatic region result is unreliable.
WhereCreate a per-game Master System region override set to Export.
Full detailIn SMSHawk's sync settings, choose Console Region: Export for this game only. Its database entry requires a BIOS but leaves the region blank, so Auto can choose Japan and produce black video even with valid firmware.

Confirm a Visible Hub

System task

HintDo not accept a successful content load alone.
WhereWait through the BIOS and title, then enter the isometric outdoor map.
Full detailA correct boot shows the Sega BIOS, the Edusoft title, and then the playable green-island hub after pressing Button 1 at the title. If the frame stays black, stop and correct the core, region, or firmware before playing.

Keep PicoDrive as the Alternate Core

System task

HintThere is a second proven route for this build.
WhereUse PicoDrive if the configured SMSHawk route is unavailable.
Full detailPicoDrive boots the unchanged prototype without the black-frame behavior observed locally in Genesis Plus GX. Preserve the same ROM hash, use native 4:3 output, and test audio and controls before beginning a completion session.

Create a Clean Hub Save State

Safety task

HintThis unfinished build can misread valid input.
WhereMake a state after the hub becomes controllable and before clearing a marker.
Full detailSave once on the untouched hub, then use separate rolling states during difficult races. Never replace the clean state with a failed reaction prompt or a two-player test; several prototype bugs can make an otherwise valid attempt unwinnable.

Question-Mark Options

You are here when: The yellow question mark in the opening green clearing.

Inspect every setting before committing to the one-session route.

Learn the Map Controls

Control task

HintTest movement before entering a lesson.
WhereUse the D-pad on the hub and Button 1 while standing on a landmark.
Full detailMove with the D-pad, press Button 1 to enter a map marker, use Button 2 to confirm menu selections, and press both buttons together when a menu refuses to advance with either button alone.

Review Both Player Counts

Option task

HintOne menu choice changes who takes turns.
WhereOpen the yellow question-mark menu and cycle Players through 1 and 2.
Full detailRecord both settings, then return to Players: 1 before any single-session clear. Two-player mode alternates participants and can invalidate tracking for a one-player all-marker run.

Set Both Initial Fields

Option task

HintPersonalize the two three-character slots.
WhereVisit Player 1 and Player 2 in the question-mark menu.
Full detailEnter three initials in each field and confirm them. Player 2 remains configurable even when the current run uses one player, so inspect both fields before leaving the menu.

Find the Hidden Initials Response

Secret

HintOne three-letter entry has an extra reaction.
WhereExperiment in the Player 1 initials field.
Full detailSet Player 1 to DAM and confirm it. This deliberately incomplete spelling triggers the prototype's hidden initials response; restore your preferred initials afterward.

Review Every Learning Level

Option task

HintThe challenge menu has five steps.
WhereCycle Level through Simple, Easy, Medium, Hard, and Complex.
Full detailConfirm that all five values appear. Difficulty changes word length and the star requirements for transport, so finish the menu audit before choosing the setting for a full run.

Review Every Guess Allowance

Option task

HintMistake tolerance is separately adjustable.
WhereCycle Guesses through Ten, Seven, Five, Three, and One.
Full detailInspect all five allowances, then select the value wanted for the run. This option governs the permitted selection attempts and is independent of the race speed and learning level.

Review Every Race Speed

Option task

HintThe timer has five named settings.
WhereCycle Speed through Snail, Tortoise, Hare, Leopard, and Sonic.
Full detailCheck all five values. Snail provides the widest response window; Sonic provides the shortest. Use Snail while mapping content, then return for the dedicated Sonic-speed clear.

Test Standard Letter Control

Option task

HintOne input style accepts diagonals directly.
WhereChoose Control: Standard and open a word lesson.
Full detailMove the selection cursor to each of the eight surrounding letter positions with direct D-pad directions, including diagonals. Confirm one harmless answer, then leave or reload before testing the other style.

Test 4-Way Letter Control

Option task

HintThe alternate style avoids diagonal presses.
WhereChoose Control: 4-Way and open a word lesson.
Full detailReach corner letters by pressing cardinal directions in sequence instead of attempting a diagonal. This is usually the more dependable choice for long words at Sonic speed.

Lock the Completion Settings (missable)

Preparation task

HintSet the demanding run before earning progress.
WhereReturn to the question mark immediately before the all-marker attempt.
Full detailFor the maximal route, select Players: 1, Level: Complex, Speed: Sonic, Control: 4-Way, and the guess allowance you can manage. Leave these values unchanged until every educational marker has been cleared.

Island and Transport Route

You are here when: The connected islands, gates, two helicopters, and striped hot-air balloon.

Visit each newly reachable lesson cluster before testing the next barrier.

Visit the Opening Three Markers

Route task

HintBegin around the question-mark clearing.
WhereEnter every educational icon reachable before using transport.
Full detailPlay all three starting markers at least once and repeat comfortable ones until the first helicopter's threshold is met. On Simple this means four stars; higher levels require 8, 12, 16, or 20.

Ride the First Helicopter

Route task

HintA nearby aircraft opens the first detached island.
WhereReturn to the first helicopter after visiting all three opening markers.
Full detailBoard it with the required stars: 4 on Simple, 8 on Easy, 12 on Medium, 16 on Hard, or 20 on Complex. Clear both educational icons on the island it reaches.

Open the First Gate

Route task

HintThe next bridge checks visited lessons.
WherePlay both markers beyond the first helicopter, then return to the blocked path.
Full detailThe gate opens after every currently exposed educational location in that branch has been visited. Cross it and play the three new markers, bringing the reachable total from five to eight.

Open the Second Gate

Route task

HintAnother barrier yields to broader exploration.
WhereVisit all three markers beyond the first gate, then backtrack to the lower route.
Full detailOnce the eight-marker wave has been visited, pass the newly opened lower gate and play all four educational markers in the next section. The reachable total is now twelve.

Ride the Hot-Air Balloon

Route task

HintThe striped balloon needs both exploration and stars.
WhereAfter the twelve-marker wave, build the required star total and return to the balloon.
Full detailBoard with 14 stars on Simple, 28 on Easy, 42 on Medium, 56 on Hard, or 70 on Complex. Play the two markers at its destination, raising the visited total to fourteen.

Ride the Second Helicopter

Route task

HintOne aircraft passed earlier becomes useful late.
WhereAfter both balloon-side markers, backtrack to the remaining helicopter.
Full detailBoard with 17 stars on Simple, 34 on Easy, 51 on Medium, 68 on Hard, or 85 on Complex. Its destination contains the final two educational markers, for sixteen total.

Clear the Final Two Markers (missable)

Route task

HintFinish the isolated pair reached by the late helicopter.
WhereEnter both educational icons at the aircraft's destination.
Full detailWin both races and confirm that every earlier marker has also been cleared during this session. If the completion screen does not appear, repeat a quick known marker to build the remaining stars.

Reach the Completion Star Total (missable)

Completion task

HintClearing all locations and filling the counter are separate checks.
WhereRepeat any reliable lesson after all sixteen markers have been visited.
Full detailReach 27 stars on Simple, 54 on Easy, 81 on Medium, 108 on Hard, or 135 on Complex. With every educational marker visited, the prototype then displays its completion message.

Coffee-Break Games

You are here when: The three balloon-cluster landmarks away from the chalkboards.

These one-minute skill games are separate from star progression.

Complete Balloon Pop

Skill game

HintLook for one of the balloon-cluster markers.
WhereEnter the half-pipe game and target coloured balloons.
Full detailSend Sonic across when a red or blue balloon is aligned; each is worth 100 points. Avoid grey balloons because touching one ends the attempt. Reach at least 300 points and, for a full survival, continue until the one-minute timer expires.

Complete Trampoline

Skill game

HintA second balloon marker uses a movable catcher.
WhereKeep the trampoline beneath Sonic as he crosses the screen.
Full detailHold near the centre until the jump direction is clear, then slide under the landing point. Each successful bounce scores 100; touching the floor ends the run. Survive the full one-minute timer.

Complete the Running Game

Skill game

HintThe remaining balloon marker starts an automatic run.
WhereUse both action buttons to test the short and long jumps.
Full detailJump over every ground obstacle and collect at least one red or blue balloon for a positive score. Use the smaller hop for close debris and the longer leap for broad gaps; any collision ends the attempt, so survive to the one-minute limit for a clean clear.

Visit Every Coffee-Break Marker

Skill-game set

HintThe skill games do not open transport.
WhereFind all three balloon clusters while traversing the hub.
Full detailRecord a completed Balloon Pop, Trampoline, and running-game attempt. They award no progression stars, so do them separately from the educational route and reload if a prototype bug ends a run without your input.

Completion and Mastery

You are here when: The fully opened hub after all vehicles and gates are usable.

Keep maximal difficulty, counter, and two-player work on deliberately separated states.

Clear All Sixteen in One Session (missable)

Mastery task

HintDo not switch player mode midway.
WhereStart from the opening hub and win every educational marker without resetting progress.
Full detailKeep Players set to 1, clear both copies of every math operation and every word theme, and use all three transports as they unlock. Maintain a rolling save state, but do not load a state from another option set.

Clear Everything on Complex at Sonic Speed (missable)

Mastery task

HintReserve the hardest option pair for a dedicated run.
WhereSet Level to Complex and Speed to Sonic before clearing any marker.
Full detailUse 4-Way control, keep Players at 1, and clear all sixteen educational markers without changing either difficulty setting. Build to 135 stars if the completion screen has not appeared after the final marker.

Win Without Rival Progress (missable)

Mastery task

HintChoose a lesson whose answers you know instantly.
WhereAt Sonic speed, finish one race before the opponent advances.
Full detailUse a short math lesson or a memorized word group, answer seven prompts correctly, and avoid every timeout or wrong selection. Reload immediately if the opponent moves even once.

Win Before the Countdown Cue (missable)

Mastery task

HintFast recognition can end a race unusually early.
WhereSelect Sonic speed and choose a familiar marker.
Full detailAnswer each prompt as soon as it settles and earn the seventh correct response before the urgent countdown music begins. A Simple math board is the safest rehearsal; repeat on Complex for the maximal version.

Collect 100 Stars

Counter task

HintThe counter continues beyond the ending threshold.
WhereRepeat a reliable educational marker after transport is fully open.
Full detailKeep winning the fastest comfortable lesson until the total reaches 100. Coffee-break games do not add stars, so use a short math board or a memorized three-letter word bank for the repeat cycle.

Fill the Star Counter

Counter task

HintThe prototype stores more than completion requires.
WhereContinue repeating educational wins after reaching 100.
Full detailRaise the counter to its 255 maximum by farming the quickest dependable marker. Make a separate save state first: this is a counter-cap exercise, not a requirement for the normal completion screen.

Complete a Two-Player Lesson (missable)

Mode task

HintThe second participant setting deserves its own test.
WhereSet Players to 2 only after finishing the one-player mastery run.
Full detailGive both participants initials, enter an opening marker, and complete enough turns to observe the handoff. Save this as a separate branch, because enabling two-player mode breaks continuity with the single-session one-player clear.
