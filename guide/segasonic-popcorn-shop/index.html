Cabinet Setup and Inputs

You are here when: The emulator launch window, machine-specific input list, and service controls before a customer cycle begins.

Use the preserved Rev B set. MAME reproduces the screen and sound, but not the vending machinery.

Verify the Rev B Build

System task

HintConfirm the archived machine set before remapping inputs.
WhereRun MAME's ROM check against shortname sonicpop.
Full detailUse the 375,267-byte sonicpop.zip archive. Its SHA-1 is bb4af9a31745b8bf44dd582b5c45e3fa315b3a89 and SHA-256 is d9a1512157db4af1f06da3a7895bfd23aba0f082b8a452a823b73c9604a000be; MAME 0.289 must report the set as good.

Confirm the Mechanical Boundary

System task

HintSeparate the video program from the food hardware.
WhereCheck MAME's machine status before starting a transaction.
Full detailConfirm that video and audio are marked good while the driver remains preliminary and mechanical. The emulator can finish the animated sequence, but it cannot heat, season, drop, or present real popcorn; never treat an on-screen completion as a physical dispense test.

Map Coin 1

Cabinet input

HintGive the customer credit input its own binding.
WhereBind Coin 1 in the machine input list.
Full detailAssign Coin 1 to a separate key or controller button, return to attract mode, and press it once. The screen should leave its idle sequence and open the three-choice panel without requiring a Start input.

Map Cup Select 1

Cabinet input

HintThe first flavour line uses one dedicated switch.
WhereBind Cup Select 1 under this machine's inputs.
Full detailAssign Cup Select 1 to an individual button and test it only after inserting a credit. It must choose the left/green panel option by itself; release it before the animated preparation begins.

Map Cup Select 2

Cabinet input

HintA second flavour line needs another switch.
WhereBind Cup Select 2 separately from Cup Select 1.
Full detailAssign Cup Select 2 to a different button, start a fresh transaction, and confirm it chooses the middle/yellow option without the first switch being held.

Map the Third Cup Combination

Cabinet input

HintThe final flavour shares both selection lines.
WherePrepare a binding that can assert both Cup Select inputs together.
Full detailInsert a new credit, press Cup Select 1 and Cup Select 2 at the same time, then release both. The simultaneous pair selects the right/red option; pressing the switches sequentially can commit an earlier choice instead.

Map Both Crank Phases

Cabinet input

HintThe wheel is represented by two alternating signals.
WhereBind Handle A and Handle B to two reachable controls.
Full detailAssign both handle phases and test them by alternating A-B-A-B during a help prompt. Do not hold both continuously: the original wheel produces changing phase signals, so repeated alternation is what the software reads as rotation.

Map the Relay

Cabinet input

HintOne hidden cabinet signal confirms mechanical progress.
WhereBind the machine input named Relay and note that it toggles.
Full detailAssign Relay to its own key, engage it before the credit, then change its state only when the animation waits for the absent vending mechanism. A permanently inactive line faults immediately, while a fixed state can stall later and open the assistance screen.

Map the Service Controls

Operator input

HintKeep diagnostics away from customer buttons.
WhereLocate Service Mode, Service 1, and Service 2 in the input list.
Full detailGive all three service lines distinct operator-only bindings. Enter diagnostics from attract mode, record which control moves or confirms each page, then leave without inserting a customer credit; do not mix the reset/service line with Cup Select 2.

Three-Choice Panel

The screen identifies choices by position and colour. Complete each one on a separate customer cycle.

Customer action

WhereInsert one Coin 1 credit while the relay is engaged.
Full detailFrom attract mode, confirm no sold-out line is asserted, engage the Relay, and press Coin 1 once. Wait for the green-yellow-red panel; do not press a cup input while the opening transition is still playing.

Flavour choice

Record the Red Choice (missable)

Flavour choice

WherePress both Cup Select inputs simultaneously.

Full detailComplete one transaction from each coloured button and retain evidence of the selected panel picture plus its prepared cup. The cabinet offers salt, butter, and curry, but the emulated screen does not provide reliable English labels, so colour and position are the fail-safe identifiers.
