Back up save-RAM externally because all three in-game slots can be lost together.

Full detailLaunch the original Game Boy Color release on working hardware or an accurate emulator. Create a dedicated cartridge backup or save-RAM file; no port, remake, remaster, or secondary platform adds content to this route.

Back Up the Cartridge Save

Save Safety

HintRare reports describe spontaneous loss of all three slots.
WhereCopy the cartridge save or emulator save-RAM before each session.
Full detailDump the battery-backed save from original hardware when possible, or duplicate the emulator's save-RAM outside its active folder. Keep rotating dated copies because an occasional restart-and-slot-loss fault has been reported and cannot be prevented from inside the game.

Use All Three Save Slots

Save Rule

HintThe game offers fixed save prompts rather than free saving.
WhereRotate saves across Slots 1, 2, and 3 whenever prompted.
Full detailAt each prompted save window, write to the oldest of three rotating slots and wait for completion before continuing. Never rely only on Continue: it resumes the active checkpoint, while the numbered slots preserve earlier recovery positions.

Accept Every Save Prompt

Save Rule

HintA declined opportunity cannot be reopened at that moment.
WhereSave whenever the game offers one of fourteen fixed windows.
Full detailChoose Yes at every save prompt, rotate to the next slot, and make an external save-RAM backup afterward. If you walk beyond a prompt without saving, continue to the next checkpoint or restore the preceding slot; the missed window does not remain interactable.

Unlimited Inventory Ledger

System

HintEvery route item can remain carried together.
WhereKeep keys, weapons, armor, herbs, and documents instead of discarding them.
Full detailOpen the inventory after each pickup and verify it appears under the correct character or shared item list. Ammunition for each weapon stops at 99, but the inventory itself has no slot limit, so discard only an equipped item when deliberately changing equipment.

Use All Three Playable Characters

System

HintParty members can carry separate weapons and armor.
WhereEquip and control Barry, Leon, and Lucia during available phases.
Full detailWhen more than one character is present, switch with B from the inventory or battle interface. Give each playable character a weapon and armor, land at least one successful attack with each, and keep the healthiest member active during dangerous travel.

Master the Moving Target Bar

System

HintCentered timing deals substantially more damage.
WherePress the action button as the cursor crosses the target's central square.
Full detailEnter battle from a safe distance, watch the horizontal cursor, and fire when it overlaps the small weak-point square inside the wider body bar. Stronger weapons move the cursor faster, so practice with the Handgun before spending rare launcher ammunition.

Complete a Battle Escape

System

HintRunning uses a separate red target without consuming ammunition.
WherePress Start in battle and hit the Run Target exactly.
Full detailActivate Run mode, wait for the red escape marker to align, and press the action button once. Enemies continue attacking while the marker moves and you cannot cancel back into ordinary battle, so attempt this with enough health and distance.
