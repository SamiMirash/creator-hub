    How a game gets picked

    Every game here is chosen the same way, and the rules are worth stating plainly because they explain the odd-looking answers — like why a remaster sometimes does not replace the original.

    Life is short, so: the fewest playthroughs per game

    The goal is never “play every version”. It is to play a game once, in the version that gives the whole thing. So the first question is always whether a single release carries both the most complete content and the best image quality. If one does, that is the only one on the list.

    …unless something was cut. Then it has to be two.

    If the best-looking version censored or removed even one thing — a scene, an item, a level, an altered boss — it stops being the complete version. At that point there is no single release that has everything, so it becomes two playthroughs: the original for the content that was taken out, and the remake for the presentation.

    One removed thing is enough. There is no threshold and no “close enough”.

    Anything unique makes a release mandatory

    The test for whether a release belongs on the list is simple: does it contain anything that exists nowhere else? A game, a level, a story beat, an item, a mode. If yes, it is required — even if it is a tool rather than a game, and even if it is a version most people would skip.

    If it contains nothing exclusive, it is skipped — no matter how it is marketed. A collection of three games already on the list does not become a fourth entry just because it is sold in one box.

    Release order, with a game's versions kept together

    Franchises are played in release-date order, not story order. Where one title needs more than one version, those versions are played back to back rather than scattered across the years, and the group sits at the date of the earliest of them.

    Demos, betas, prototypes and test builds are not entries. Community content counts only when it was officially bundled with the game.

    A drastically different port is its own game

    A port that merely runs the same game elsewhere is not a separate entry. A port that changes what the game is — different levels, different content, different balance — is, and gets played on its own terms.
